E-Commerce Application

An e-commerce application developed in **Java and Python** to strengthen my understanding and practical application of Object-Oriented Programming (OOP) and SOLID design principles.

## Overview

This project simulates the core operations of an e-commerce system, including product management, inventory management, customer operations, shopping cart management, checkout and payment processing.

The application is implemented in both Java and Python to explore how object-oriented concepts and software design principles can be applied across different programming languages.

Features

- **Product Management:** Create and manage products and their prices.
- **Inventory Management:** Add stock, update product quantities, change prices and search for products.
- **Customer Management:** Handle customer shopping operations.
- **Shopping Cart:** Add, view and remove products from the cart.
- **Checkout:** Review cart contents and calculate the total purchase amount.
- **Payment Processing:** Process payments through a payment gateway abstraction.

Object-Oriented Programming Concepts

The project explores:

- Encapsulation
- Abstraction
- Inheritance
- Polymorphism
- Composition
- Dependency Injection

SOLID Principles

The application focuses on understanding and applying the five SOLID principles:

- Single Responsibility Principle (SRP)
- Open/Closed Principle (OCP)
- Liskov Substitution Principle (LSP)
- Interface Segregation Principle (ISP)
- Dependency Inversion Principle (DIP)

**Python**

## Testing

Both implementations include unit tests to verify class behaviours and interactions between components.

Mock objects and test doubles are used to isolate dependencies and test individual components independently.

## Project Goal

The goal of this project is to strengthen my understanding of OOP and SOLID principles through practical implementation in Java and Python, while developing the ability to write clean, maintainable and testable code.
